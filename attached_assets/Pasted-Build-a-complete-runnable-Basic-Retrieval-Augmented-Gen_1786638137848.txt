FUNCTIONAL REQUIREMENTS:

1. DOCUMENT UPLOAD
   Create a Streamlit interface where the user can upload PDF and TXT documents.

2. DOCUMENT PROCESSING

* Extract text from uploaded PDF/TXT files.
* Clean the extracted text.
* Split the documents into meaningful chunks.
* Use a reasonable chunk size and overlap.
* Preserve document name and chunk metadata.

3. EMBEDDINGS

* Generate embeddings for document chunks using an OpenAI embedding model.
* Store the embeddings in a FAISS vector index.
* Save enough metadata so that retrieved chunks can be traced back to the original document.

4. RETRIEVAL
   When the user enters a question:

* Generate an embedding for the question.
* Search the FAISS index.
* Retrieve the top-k most relevant chunks.
* Make k configurable, with a sensible default such as 5.
* Display the retrieved evidence/source chunks in the interface.

5. GENERATION
   Send the user question and retrieved context to an OpenAI LLM.
   The prompt should instruct the LLM:

* Answer using the retrieved context.
* Do not invent information that is not supported by the context.
* If the context is insufficient, clearly say that the available documents do not contain enough information.
* Provide a concise answer.
* Clearly separate the answer from the retrieved sources.

6. SOURCE DISPLAY

* Answer
* Retrieved document names
* Relevant retrieved text/chunks
* Similarity/relevance scores if available
